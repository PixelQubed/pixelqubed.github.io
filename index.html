Programming / Agent-assisted systems

Tools that help
the work happen.

Alongside my art, I use agents to help build software, investigate complex codebases and develop practical workflows.

  • An evidence-led S&box handbook. A searchable, snapshot-based API reference with exact declarations, connected flows and visible evidence.
  • Workflow and repository tooling. Local tooling for coordinating work, preserving ownership and checking changes before delivery.
  • Creative pipeline investigations. Tools and investigations for understanding asset formats and improving the software around creative work.

My artwork does not, and will not, involve AI agents or agentic tools at any stage.
Agent-assisted work belongs to my programming and workflow practice.
